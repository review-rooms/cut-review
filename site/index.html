cut-review turns your renders into a private review room on claude.ai. Watch each cut on any device, pause and type what's wrong. Say “apply my notes” and Claude changes whatever made the video, re-renders it, and answers every note.

How it works

One loop, from first render to sign-off. You stay in the room; Claude does the rest from a Claude Code session.

Make a room

Make a review room for the videos in renders/. Claude publishes a private page, uploads your cuts, and sends you the link.

Leave notes

Pause on a frame and type. Mark a time range, box part of the picture, or select words in the voice-over script. Give each cut a verdict.

Apply them

Apply my notes. Claude reads every note with the frame behind it, edits the source, re-renders, swaps in v2 and replies to each note. You press Looks right or Still wrong.

Made for reviewing renders

Everything a note needs to be unambiguous, so the fix is right the first time.

Frame-exact notes

Every note carries its timecode, a range or a region of the frame.

Script notes

Select a word or a whole line of the voice-over and say how it should change.

Sets and carousels

Comment on stills and clips of a carousel, item by item.

Versions

A cut goes up a version only when its video changes, with a note on what changed.

Any device

Review on your phone, laptop or the Claude app. The room is a private claude.ai page.

Open source

A Claude Code plugin and a small Python CLI, standard library only. MIT licensed.

Install

You need Claude Code and uv. Then, in a terminal:

claude plugin marketplace add review-rooms/cut-review
claude plugin install cut-review@cut-review

Start a new Claude Code session and ask:

# in your project
Make a review room for the videos in renders/
# later, after you've left notes
Apply my notes
